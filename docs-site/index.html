Mail Buddy

An open-source, self-hostable email template manager and delivery API. Ships as one compiled binary — no Docker, no separate frontend deployment, no external database process.

Read the docs View on GitHub

What's implemented

An Elysia (Bun) API server with a React admin dashboard embedded directly into the executable.

Template CRUD

Handlebars placeholder auto-extraction and recursive {{embed "uuid"}} resolution with cycle detection.

Asset uploads

Local storage today, with an S3 driver stubbed for future support.

Single & batch send

A SQLite-backed delivery queue with an exponential-backoff retry worker, plus personalized batch sends.

Scoped API keys

Database-backed admin / send_only keys, optionally restricted to specific origins or IPs.

Suppression lists

Per-template and global suppression, with signed one-click unsubscribe links.

Typed Node SDK

mail-buddy-sdk covers every endpoint — built, typechecked, and unit tested.

Quickstart

Requires Bun 1.x.

bun install                # installs all workspaces (apps/api, apps/web, packages/sdk)
bun run web:build          # builds the dashboard to apps/web/dist
bun run api:start          # generates the embedded-asset manifest, runs migrations, starts the server

Open http://localhost:3000 and paste the one-time admin key printed on first boot into the login screen.

Single binary, minimal footprint

The API server and the dashboard both live inside the binary — only three things live outside it.

mail-buddy              # the binary itself (API + dashboard)
.env                    # optional - config; Bun loads this automatically from the cwd
mail-buddy.sqlite       # the database (path configurable via DATABASE_PATH)
uploads/                # locally-stored assets (path configurable via UPLOADS_DIR)

Or grab a prebuilt binary from GitHub Releases instead of compiling one yourself.
