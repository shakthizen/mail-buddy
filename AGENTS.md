# Agent Instructions & Guidelines for Mail Buddy

## Documentation & Changelog Policy
Whenever you implement features, add/modify API endpoints, update database schemas, or revamp UI in Mail Buddy:
1. **Always update `CHANGELOG.md`** under `## [Unreleased]`.
2. **Always update `README.md` and `packages/sdk/README.md`** with accurate instructions, code examples, and features.
3. **Always update `docs-site/index.html` and `docs-site/docs.html`** to reflect current architecture and capabilities.
4. **Follow the `.agents/skills/sync-docs` skill** workflow before committing changes.
